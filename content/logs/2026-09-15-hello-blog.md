## 今天做了什么

- 搭建了基于 Hugo + PaperMod 主题的静态博客
- 部署到 GitHub Pages:`avddhtghd.github.io/phd-blog`
- 配置了 GitHub Actions 自动构建部署,push 即上线

## 这个博客怎么运转

每次工作结束后,把当天的任务、进展、遇到的问题整理成一篇日志,
提交到仓库后由 Actions 自动构建发布。日志在 `/logs/` 下,
论文阅读和方法调研放在 `/notes/` 下。
